1️⃣ What is the difference between var, let, and const?



ans: var is the old way. It can cause problems. By var variable name can be duplicate

let is the new way to make a variable that you want to change later. (Example: let score = 10; then later score = 20;)
const is for things that should NOT change. (Example: const myName = "John"; You cannot change myName later.)

3️⃣ What is the difference between map(), filter(), and forEach()?


ans:forEach() is simple. It just does something for each item.For looping Array we used it. By it we can get inner elements of an array
filter() is for when you want a smaller list. 

map() is for when you want to change every item and make a new list of the same size. (Example: Take a list of numbers and make a new list where every number is doubled.)
